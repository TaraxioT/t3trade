The decision

Ship the moment a conversation becomes a working instrument. Forge is the new primary research workflow inside T3 Trade: inspect three real Uniswap pools → author an executable detector → test → install → chart it → attach its output to one fixed v4 fee hook → revise it in the same conversation.

This is a hackathon plan, not a general plugin platform or production trading rollout. Two focused implementers are recommended: one application/data owner and one contracts owner. A single implementer should expect roughly 30–36 focused hours and substantial schedule risk. Gates can stop dependent work; they must never be waved through to hit a date.

Finish line: a detector that did not exist at the start is built by the product agent, appears in the existing chart workspace, and changes a real testnet pool’s fee behavior. A second natural-language request creates an immutable v2, changes the real-data indicator, and produces inspectable fee-policy and swap receipts. Data contract and freshness policy

Start with 60-second completed windows, a 5-minute price lookback and a 15-second Graph health check. These are proposed demo settings; freeze measured settings at F0. Use one common indexed block B across all three pools. Fetch _meta first, confirm B/hash via Ethereum RPC and pin every page to B. No latest-per-pool joins. Indexed head lag must be ≤120 seconds for policy publication; source window end must be ≤180 seconds old. Policy expires at sourceWindowEnd + 180 seconds, never readTime + 180. Testnet hook also caps lifetime. If real measured latency cannot satisfy those settings, disclose and agree a slower cadence in F0; do not silently extend freshness later.

  • Query bounded swaps for each pool, page by a deterministic ID cursor, pin block B, deduplicate by chain/transaction/log index and sort by block/log order after collection. The query below assumes the selected deployment exposes these fields; introspect its actual schema and test the adapter. Missing log ordering is a capability gap to resolve, not a reason to guess.
  • Capture all bounded anchor candidates from the 5 minutes preceding the lookback start, plus all swaps through the window end, using the same block and pagination rules. v1 selects the latest anchor at/before start; v2 selects the latest qualifying anchor there. Reject missing anchors or anchors older than that 5-minute allowance and stale terminal prices. If the nearest anchor is tiny, an earlier qualifying trade must still be available. If caps prevent complete candidate coverage, mark incomplete rather than selecting from a truncated set. A complete query with no trades is genuine inactivity; a failed/truncated query is unavailable. Never confuse the two.
  • Normalize each pool to USDC per WETH from sqrtPriceX96 and token decimals using exact integer/rational arithmetic. For raw token1/token0 ratio r = sqrtPriceX96² / 2¹⁹², human ratio is r × 10^(decimals0−decimals1). Invert when WETH is token1. Compute movements in basis points, stable-quote volume from absolute USDC leg once per swap; no double-counting both legs. Call it USDC not USD unless a separate verified conversion exists.
  • Hard cap source work: three pools, 1,000 records/page, 10,000 records/pool/window, 20-second fetch budget, at most 24 hours of authentic comparison history (bounded pages; do not scan the whole chain). If capped, return incomplete and stop policy publication. Keep raw evidence outside WS payloads; paginate chart results to at most 720 samples.
  • Only accepted blocks produce installed signal readings. Store provenance and raw response digest. On an observed block-hash mismatch, invalidate affected observations, stop new policy writes and recompute a canonical window. Already-mined testnet transactions remain real receipts; do not rewrite them.

Detector semantics — small enough to understand on stage

Define “coordinated” as directional agreement, not causation or an alpha claim. For the three known pools, compare price over the same 5-minute lookback. Ignore movement below 2 bps. Two or more eligible pools moving in the same direction means coordinated; exactly one eligible moving pool means isolated; zero means quiet; opposing moves without a two-pool majority mean insufficient/conflicting. F0 may tune lookback/2 bps from actual activity once, before the demo; store the choice in the manifest.

Version 1 counts all valid trades. Version 2 adds both a per-trade quote-notional floor and a per-pool qualifying-volume floor. Only trades meeting the per-trade floor contribute qualifying volume and qualifying price anchors/endpoints; each eligible pool must pass the cumulative floor. This is stronger than merely changing a fee number. The display shows all market activity as context and separately identifies the activity used by v2. Suggested starting thresholds: 100 USDC per trade and 10,000 USDC per pool in the lookback, subject to inspection of actual data. Do not claim fixed thresholds are economically optimal.

export function classify(
  pools: readonly PoolWindow[],
  minPoolQuoteMicros: bigint,
  movementBps: number,
): SignalReading {
  if (pools.length !== 3 || new Set(pools.map(p => p.poolId)).size !== 3) {
    return { kind: "insufficient", reason: "need_three_distinct_pools" };
  }
  const eligible = pools.filter(p =>
    p.tradeCount > 0 && BigInt(p.quoteVolumeMicros) >= minPoolQuoteMicros);
  if (eligible.length === 0) {
    return { kind: "insufficient", reason: "volume_below_floor" };
  }
  const moving = eligible.filter(p => Math.abs(p.moveBps) >= movementBps);
  const up = moving.filter(p => p.moveBps > 0);
  const down = moving.filter(p => p.moveBps < 0);
  const ids = eligible.map(p => p.poolId);
  if (Math.max(up.length, down.length) >= 2) {
    return { kind: "ready", regime: "coordinated",
      agreement: Math.max(up.length, down.length) / 3, eligiblePoolIds: ids };
  }
  if (moving.length === 1) {
    return { kind: "ready", regime: "isolated", agreement: 1 / 3,
      eligiblePoolIds: ids };
  }
  if (moving.length === 0) {
    return { kind: "ready", regime: "quiet", agreement: 0,
      eligiblePoolIds: ids };
  }
  return { kind: "insufficient", reason: "opposing_moves" };
}

One fixed hook, not unrestricted contract generation

Use a beforeSwap fee override, backed by operator-published state and local expiry. This makes the baseline work even when the off-chain worker is offline. Core dynamic fee values are hundredths of a basis point; 500 is 0.05%, 3000 is 0.30%. PoolKey.fee is the dynamic flag 0x800000; returned overrides include 0x400000. The permissioned hook address must encode the enabled hook bits. LPFeeLibrary and Hooks are the source for these mechanics.

Proposed implementation below uses OpenZeppelin’s BaseHook interface as currently published. It is an authored starting point to compile/test against pinned dependencies, not a claim of audited code or a tested deployment. The agent can configure bounded thresholds/fees; it cannot edit this contract during the demo. Pin its source and bytecode hash before F3. BaseHook source.

    event PauseChanged(bool paused);

        uint64 validUntil, bytes32 observationHash, bytes32 moduleHash);

        if (owner_ == address(0)) revert Refused();

        returns (Hooks.Permissions memory permissions) {

    function bind(PoolKey calldata key) external {
        if (msg.sender != owner || bound || address(key.hooks) != address(this)
            || key.fee != DYNAMIC_FLAG) revert Refused();
        boundPool = PoolId.unwrap(key.toId());
        bound = true;
        emit PoolBound(boundPool);
    }
    function setOperator(address next) external {
        if (msg.sender != owner) revert Refused();
        operator = next;
        paused = true;
        validUntil = 0; // no accidental reuse after authority changes
        emit OperatorChanged(next);
        emit PauseChanged(true);
    }
    function setPaused(bool next) external {
        if (msg.sender != owner) revert Refused();
        if (!next && operator == address(0)) revert Refused();
        paused = next;
        validUntil = 0; // resume needs a fresh observation
        emit PauseChanged(next);
    }
    function publish(uint64 nextRevision, uint24 fee, uint64 expiresAt,
        bytes32 observation, bytes32 module_) external {
        if (msg.sender != operator || !bound || paused
            || nextRevision != revision + 1
            || (fee != 500 && fee != BASELINE_FEE)
            || expiresAt <= block.timestamp
            || expiresAt > block.timestamp + 180
            || observation == bytes32(0) || module_ == bytes32(0)) revert Refused();
        revision = nextRevision;
        policyFee = fee;
        validUntil = expiresAt;
        observationHash = observation;
        moduleHash = module_;
        emit PolicyPublished(nextRevision, fee, expiresAt, observation, module_);
    }
    function effectiveFee() public view returns (uint24) {
        if (paused || block.timestamp >= validUntil) return BASELINE_FEE;
        return policyFee;
    }
    function _beforeSwap(address, PoolKey calldata key, SwapParams calldata, bytes calldata)
        internal override returns (bytes4, BeforeSwapDelta, uint24) {
        if (!bound || PoolId.unwrap(key.toId()) != boundPool) revert Refused();
        return (IHooks.beforeSwap.selector, BeforeSwapDeltaLibrary.ZERO_DELTA,
            effectiveFee() | OVERRIDE_FLAG);
    }
