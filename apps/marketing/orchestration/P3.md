# P3: token extraction pipeline

Mission: make the replica's design tokens flow mechanically out of apps/web.

## Status: COMPLETE (pending orchestrator review)

## What shipped
- `scripts/extract-app-tokens.mjs`: parses apps/web/src/index.css + trading.css
  (`:root` blocks + nested `@variant dark` + `@theme` font stacks), resolves var
  chains, `--alpha()`, `calc()` (radius ladder, rem<->px at 16), and Tailwind
  palette refs via tailwindcss/theme.css resolved from apps/web's deps. Emits
  dark-mode literals as `--app-*` custom properties. Also regenerates
  `src/lib/icons.ts` from lucide-react dist/esm/icons `__iconNode` literals
  (React-only `key` props dropped).
- `src/styles/app-tokens.generated.css`: generated, on disk (committed at ship
  time by the orchestrator). Contains background, card, foreground,
  muted-foreground, border, primary, info, profit/loss/long/short/armed, radius
  + sm/md/lg/xl ladder, chart wash/wedge opacities, font-sans/font-mono.
- `src/lib/icons.ts`: 23 lucide glyphs (enumerated from MissionLivePanel.tsx and
  MissionHeaderPill.tsx) + `renderIcon(name, {size=11, strokeWidth=2, class})`
  Astro-safe SVG string helper. Zero hand-written path data.
- Build wiring: package.json `build` now runs
  `node ./scripts/extract-app-tokens.mjs --check` FIRST, then astro build, then
  check-scroll-timelines. Check mode regenerates in memory, asserts the P1
  oracle, diffs against disk; skips the token half (still checks icons) when
  apps/web is absent. Read-only on shared output -> concurrency-safe.
- Dependency: `lucide-react@0.564.0` added as marketing devDependency, exact
  pin matching the app's lockfile resolution (pnpm dir
  `lucide-react@0.564.0_react@19.2.6`). Icons are read from its dist files, so
  no react peer is ever imported.

## Notes / decisions
- `--card` and `--muted-foreground` are emitted as `color-mix(...)` with fully
  resolved literal operands (standalone-usable, exact); the app defines them
  that way and computing a flattened srgb value would lose fidelity.
- Oracle assertions live in the script's ORACLE array and run in --check mode,
  i.e. every build, so a resolution regression fails the build loudly.
- Did NOT touch index.astro, Layout.astro, components, tokens.css, replica.css
  (P2's). astro.config.mjs untouched (cssMinify: false preserved).
