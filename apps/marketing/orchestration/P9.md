## Fixes by census defect number

1. **Log feed rests at top** (AgentLog.astro). The strip now carries inline
   `--feed-rest` / `--feed-rest-phone` / `--feed-rest-mid` custom props
   computed in the frontmatter from the last `feedStops` shift of each
   variant; scoped CSS rests `.log-feed-inner` at
   `translateY(var(--feed-rest...))` per breakpoint. The follow animation
   overrides the transform wherever it runs (animations beat inline-driven
   base declarations), so animated behaviour is unchanged.
2. **Position state tokens never close** (Positions.astro). Root cause found
   beyond the census: the old `swap-in` keyframes ended at `translateY(0)`,
   which left the met token one row BELOW the 15px window - Closed/Done never
   showed even on the animated page (verified live pre-fix). Fix: new
   `.armed-stack` inner element (the clip box `.armed-swap` never transforms;
   a transform on the clip box carries the window away, the same trap the log
   feed documents). Stack rests at `translateY(-15px)` (met state in the
   window); `swap-in` runs 0 -> -15px, steps(1,end); the timeline wiring in
   `replica.css` now targets `.armed-stack` (both selector lists). Live and
   reduced-motion now both resolve to Closed / Done (verified visually and by
   geometry: metTop == swapTop).
3. **Positions table + status bar aria-hidden with nothing left behind.**
   Added `.sr-only` utility (Layout.astro) and three text alternatives, all
   derived from the mission fixture, never literal digits:
   - Positions.astro: "Mission outcome: opened a long of 0.0536 BTC at 20x on
     BTC, entry 75,810.4, stop 75,460.9, target 76,763. Position closed at
     the target for a profit of +$51.06, return +24.79% on margin. ..." (in
     dist, grep-able).
   - StatusBar.astro: "Status bar at the end of the mission: mission
     complete. Target 76,763 reached by 5:24 PM. Funding 0.0013%/8h. ..."
   - AgentLog.astro: "Progress rule: the run reached 100 percent of the
     target and closed there." (the "N% to target" alternative).
4. **fg-faint as text ink** - retired for text, kept for decoration. The four
   chrome sites now use `--fg-dim`; the token itself is untouched (still used
   for status dots, the entry level stroke, the scroll-tape gradient, and
   scoped inside .appwin where it resolves to the app's muted foreground).
   See contrast table below.
5. **rr figures / chip captions opacities** - AFFIRMED as replica fidelity
   (see below), covered by the chart SVG's role="img" aria-label and the new
   sr-only alternatives.
6. **1.29 MB dead icons** - `public/icon.png` and `public/icon.webp` deleted
   (grep across src, astro.config, vercel.ts, wrangler.jsonc, scripts,
   dist/index.html, dist/_astro: zero references). 1,315,956 bytes saved per
   deploy.
7. **Stop-hold rests invisible** (Chart.astro). Base now rests at the flare's
   100% frame: `opacity: 0.32; stroke-width: 2`.
8. **Scroll-tape / nav-settle unguarded** (Layout.astro). The
   `@supports (animation-timeline: scroll())` block is now inside
   `@media (prefers-reduced-motion: no-preference)`, matching the spine block.
9. **favicon.ico** - was 74,922 B multi-size; regenerated via `sips` as a
   single 32x32 ICO (4,414 B) from `favicon-32x32.png`; the link's
   `sizes="48x48"` corrected to `32x32`. 70,508 B saved.
