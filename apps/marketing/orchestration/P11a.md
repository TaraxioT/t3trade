## Key finding: theme boot wipes the harness's dark class
The harness ships `class="dark"` on `<html>`, but the app's theme boot (`apps/web/src/hooks/useTheme.ts`, `applyThemePalette` path) reads `t3code:theme-appearance-mode` from localStorage and re-applies the palette on mount; with no stored preference it resolves light and strips the class. First captures came out light-theme. Fixed in the capture script only (no source edits): `addInitScript` seeds `localStorage["t3code:theme-appearance-mode"] = "dark"` before app scripts run, and the settle condition asserts `documentElement.classList.contains("dark")`. Any future harness capture must do the same.
