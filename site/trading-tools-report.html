Server Guardrails, Sizing Ceilings, and Refusal Codes

The server is authoritative; the agent cannot override financial safety invariants. An order request is bound by the strictest of five distinct sizing ceilings.

Ceiling 1
requested
The size explicitly requested by the AI harness. Sizing never silently exceeds this value.
Ceiling 2
gross_notional
The maximum USD total exposure permitted by the active workspace mandate in TRADE.md.
Ceiling 3
leverage
The maximum venue leverage ratio configured for the asset pair (prevents liquidation shock).
Ceiling 4
account_margin
Available collateral in the Hyperliquid testnet wallet. Prevents underfunded order rejections.
Ceiling 5
planned_loss_ceiling
Cumulative drawdown stop: sizeEth * abs(entry - stopPrice) cannot exceed loss budget.
